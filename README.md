# 📊 MBD - DER no Guardanapo

Projeto acadêmico de modelagem de banco de dados utilizando diagrama entidade-relacionamento (DER).

## 📌 Descrição
Este projeto apresenta a construção de um modelo conceitual de banco de dados desenvolvido de forma simplificada.

## 🧠 Conceitos aplicados
- Entidades
- Atributos
- Relacionamentos
- Modelagem conceitual

## 📷 Diagrama
O diagrama está disponível neste repositório.

## 🎯 Objetivo
Praticar a modelagem de banco de dados e organização de informações.
